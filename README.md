# 🏠 StayNest – PG & Mess Rental Platform

StayNest is a full-stack MERN web application that helps students and working professionals find **PG accommodations and mess facilities** easily in one place.

The platform allows users to search verified PG listings, explore mess services, and connect directly with owners without brokers.

---

## 🚀 Features

### 👤 User Features
- Browse PG accommodations
- Search mess facilities
- Filter by price, location, gender, amenities
- View detailed listings
- Contact PG/Mess owners directly

### 🏠 Owner Features
- Add PG listings
- Add mess services
- Upload property images
- Manage listings

### ⭐ Platform Highlights
- Clean and responsive UI
- Student-focused platform
- No brokerage system
- Fast search & filtering
- Secure authentication
